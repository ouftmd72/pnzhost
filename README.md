## Three Product Lines, Three Price Points

PNZHost offers three main server categories:

### 1. Standard Cloud
Shared resource pools with standard carrier bandwidth. IPv4 only. Budget-friendly entry point — good for dev environments, personal projects, or learning Linux.

### 2. Premium Cloud
Also shared resource pools, but upgraded to **premium bandwidth blending** and **IPv6 support** (5 dedicated IPv6 addresses included). Same price range as Standard but with noticeably better routing — especially relevant if your traffic comes from Asia, since the Premium Cloud LA node connects via China Unicom, NTT, PCCW, and more.

### 3. Dedicated Cloud
Fully dedicated resources — no sharing with other customers. Higher specs, more storage, and suitable for apps, game servers, or anything resource-intensive. Starts at $29.99/month.
